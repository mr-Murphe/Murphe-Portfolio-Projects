# Independent concept presentation — Phasefield

## Owner narrative
Three shoppers, one flower company, different jobs. One needs a gift today; another wants to explore a Mother's Day idea; a third needs to understand Secret Admirer consent. SH: timing and process guidance may help people choose with fewer avoidable mistakes. We built a strong conventional storefront first, then changed only approved guidance, ordering and context. No analytics were available and no sales improvement is claimed.

VO: DFC's public site has an 11 a.m. online cutoff, Sunday closure, a consent-gated Secret Admirer journey and product-specific lead times. These are useful constraints, not obstacles personalization can override. Reference product prices came from public pages. Seasonal Mother’s Day context, availability and visual product concepts are simulated.

Phasefield sells research-to-implementation and measured commercial learning. It does not sell magical AI or proprietary software that a merchant does not need. Existing Shopify capabilities and suitable apps remain options. If one static campaign page is sufficient, recommend it. This demo tests the proposition that reusable states make sense when shoppers change their mission within one catalog.

## Three-minute demo script
1. Open default. Point out brand expression, stable navigation, catalog, timing guidance and independent-concept label. Show a PDP and demo bag; explicitly state checkout is absent.
2. Follow `index.html?pf_mission=urgent&pf_occasion=mothers_day`. Explain that the campaign’s declared intent selects urgent guidance, not the shopper’s identity. Select under $75. Show zero-day fixtures before cutoff.
3. Open presenter controls, select 11 a.m. Same-day results disappear. Select Later date to continue; each product keeps its own lead-time fixture. Select Sunday to show closure. No actual delivery promise is made.
4. Switch to Mother's Day discovery. Style selection prioritizes suitable concepts and budget narrows the same catalog. The visitor’s choice overrides campaign context. Explain seasonal simulation.
5. Switch to Secret Admirer. Explain consent, fixed example handle, no real data field, no date guarantee and standard-gifting exit.
6. Add a fixture to bag; simulate adaptive failure. Default content returns and the baseline bag continues. Show back/forward and reset.
7. Close with the pilot: learn whether a single real campaign performs better against the improved default, including downside and support costs. No outreach is authorized in this project phase.

## Default versus adaptive
| Surface | Improved default | Adaptive addition |
|---|---|---|
| Hero | permanent expressive brand proposition | mission-appropriate guidance and CTA |
| Products | normal reference browsing | eligibility constraints, then explicit budget/style/occasion relevance |
| Fulfillment | stable policy explanation | cutoff/closure simulation changes valid timing path |
| SAP | discoverable introduction | process explanation first, date warning, standard exit |
| Catalog/cart | same source and baseline | retained; no price change or checkout dependency |

## Context in owner language
A campaign link carries a small approved label such as “urgent.” The page uses that label to choose prepared content. The shopper can change it. Unknown labels go to the ordinary store. No live AI, secret identity profile or invented stock is required.

## Financial sensitivity — IE only

Profit impact = incremental revenue × contribution margin − incremental fulfillment/support costs − implementation/maintenance costs. Margin and costs CV; no break-even claim.

## Pilot proposal — not initiated
After merchant permission: validate actual products, variants, policies, lead times, available capacity, service zones, asset rights, consent setup and staff ownership. Gather minimal aggregate sessions/orders/revenue, baseline conversion, AOV, fulfillment/support and refunds. Randomly allocate equivalent qualified campaign sessions to improved default versus adaptive treatment; preserve allocation through the journey, exclude presenter traffic, verify exposure and commerce event reconciliation. Calculate sample size from baseline and an agreed minimum detectable effect; do not fix a duration before knowing traffic. Primary metric revenue per qualified session and purchase conversion; checkout start is a proxy if low volume. Guardrails: refund/cancellation, support contacts, fulfillment exceptions, latency/CWV and escape rate. Decide expansion only if value exceeds maintenance/operational burden. Stop or roll back for misleading availability, checkout faults or material performance degradation. Neither pilot nor customer outreach started.
